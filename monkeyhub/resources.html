Web Accessibility Resources

Use these standards, guides, and tools to learn about digital accessibility and improve websites. Automated checkers can find some issues, but they cannot determine whether a site works well for people with disabilities. Combine tools with manual checks and feedback from disabled users.

Standards and authoritative guidance

  • Web Content Accessibility Guidelines (WCAG) 2.2 — the W3C technical standard for making web content more accessible.
  • W3C WCAG overview — background on WCAG versions, supporting documents, and how the guidelines fit together.
  • W3C accessibility tips — practical starting points for writing, designing, and developing accessible content.

Learn and practice

  • WebAIM: Introduction to Web Accessibility — an accessible introduction to disability, assistive technology, and common web barriers.
  • WebAIM Contrast Checker — check text and background color contrast against WCAG criteria.
  • Kaffeinated Kodemonkey WCAG Learning Center — plain-language guidance on WCAG, testing, design, development, and compliance.

Testing tools

  • WAVE Web Accessibility Evaluation Tool — see detected accessibility errors and alerts in the context of a web page.
  • axe DevTools — browser-based accessibility checks for developers and testers.
  • W3C: Evaluating Web Accessibility — guidance for combining evaluation tools with human review.

Good starting point: Check a page with an automated tool, then review keyboard access, visible focus, headings, form labels, and content at increased zoom. Automated results are a starting point, not a compliance determination.
