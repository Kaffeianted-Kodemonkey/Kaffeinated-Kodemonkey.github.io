Ongoing Website Accessibility Monitoring

Accessibility is not a one-time project. Website updates, new content, software releases, and third-party components can introduce new accessibility barriers over time. Kaffeinated Kodemonkey combines automated accessibility monitoring with scheduled manual evaluations to help organizations maintain visibility into their websites' accessibility status.

Based in Rangely, Colorado, Kaffeinated Kodemonkey supports monitoring programs for client teams across the United States.

Our monitoring service uses a third-party accessibility monitoring platform to run automated scans powered by WAVE across agreed pages for detectable accessibility issues. The pages and scan frequency are configured for the selected service scope. Kaffeinated Kodemonkey complements automated monitoring with a quarterly manual evaluation, documented in a WCAG Evaluation Audit Report (WEAR), and supporting POCC documentation within the agreed scope.

Who Benefits from Accessibility Monitoring?

This service is designed for companies with large internal and external websites, in-house development teams, and web agencies that want to add accessibility monitoring to their services. It provides ongoing scan results alongside scheduled evaluation and documentation updates to support an organization's accessibility program.

Why Choose Ongoing Monitoring?

  • Identify Potential Accessibility Regressions: Automated scans help flag detectable issues that may appear as website content, templates, and functionality change.
  • Track and Prioritize Findings: Review scan results to identify potential problem areas, investigate findings, and organize remediation work.
  • Combine Monitoring with Manual Evaluation: Scheduled manual evaluations using the DHS Trusted Tester Process complement automated scanning and assess applicable accessibility requirements that automated tools cannot fully evaluate.
  • Maintain Supporting Documentation: Receive updated evaluation reports, supporting documentation, and POCC materials according to your selected quarterly or annual schedule.
  • Manage Multiple Websites: Monitoring can support organizations and agencies responsible for overseeing multiple digital properties, subject to the selected plan and configured coverage.

How Accessibility Monitoring Works

  1. Configure Your Monitoring Scope

    Identify the websites, pages, and templates to be monitored. The monitored coverage and scan frequency are agreed during scoping based on the selected service plan and technical requirements.

  2. Run Automated Accessibility Scans

    The monitoring platform scans configured pages for detectable accessibility issues and provides results for review and follow-up.

  3. Review Findings and Prioritize Remediation

    Review scan results to identify potential issues, determine which findings require investigation, and prioritize remediation work. Automated findings may require manual verification.

  4. Perform the Quarterly Manual Evaluation

    A DHS Certified Trusted Tester performs a quarterly manual evaluation using the DHS Trusted Tester Process within the agreed scope and documents findings in a WEAR report.

  5. Update Reports and POCC Documentation

    Following each scheduled evaluation, applicable findings, supporting reports, and POCC documentation are updated to reflect that evaluation's methods, results, and documented scope.

Monitoring Supports Ongoing Accessibility

Automated monitoring and manual evaluation serve complementary purposes. Recurring scans help identify detectable issues between scheduled evaluations, while manual testing provides additional assessment of applicable accessibility requirements and user interactions.

Evaluation findings and POCC documentation reflect the scope, methods, and results of the applicable evaluation. Neither automated monitoring nor a scheduled evaluation guarantees that every accessibility barrier has been identified or that a website will remain conformant as it changes. Organizations should continue to address identified issues and reassess significant website changes.
